# axiomantic

Open-source tooling for AI-assisted engineering, systems, and the occasional weird experiment. Built and maintained by [@elijahr](https://github.com/elijahr). Serious engineering, also fun.

### Highlights
- **[`spellbook`](https://github.com/axiomantic/spellbook)** - a multi-platform harness for AI coding assistants: skills, hooks, and a shared MCP server across Claude Code, OpenCode, Codex, Gemini CLI, and ForgeCode.
- **[`momus`](https://github.com/axiomantic/momus)** - thorough AI code review as a GitHub Action, works with any LLM (OpenRouter, Anthropic, OpenAI, Bedrock).
- **[`heads-up-claude`](https://github.com/axiomantic/heads-up-claude)** - a Claude Code statusline with real-time token tracking, written in Nim.
- **[`headerkit`](https://github.com/axiomantic/headerkit)** - a C/C++ header-parsing toolkit with pluggable backends.
- **[`soong`](https://github.com/axiomantic/soong)** - summon GPU instances for AI agent workflows.
- **[`audiomancer`](https://github.com/axiomantic/audiomancer)** - an MCP server for AI-assisted music production with TidalCycles.

Themes: AI developer tooling, MCP, systems, and a little audio.
